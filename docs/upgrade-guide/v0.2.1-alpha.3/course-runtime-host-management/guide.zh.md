# 课程研究默认使用隔离 Linux

[English](guide.md) | 中文

## 变更

此前，选择 Local 后，课程研究工具仍可在本机主机上使用。讲师 `@deepseek-ai/dsh-experimental-course-runtime` 插件现在将 `allowHostResearch` 默认为 `false`，并拒绝该主机上的 ToolRuntime 执行。选择器按位置命名为主机管理和隔离 Linux；返回管理不会授予研究执行权限。

根客户端会打开网络范围设置，且仅在观测到网关健康、动作审核就绪、本机轨迹采集成功及保存版本、应用版本和运行版本一致后，才进入隔离 Linux。未知或失败的观测绝不会悄悄将研究路由至主机。选择器更改不会迁移或停止已有进程和会话。

## 迁移

1. 课程部署应在讲师 `course-runtime` Cordis 配置项中省略 `allowHostResearch` 或设为 `false`。其默认拒绝守卫会持续到应用根退出，包括插件卸载或 Tools 提供程序替换之后。讲师若有意允许可信主机研究，必须在部署配置项中设置 `allowHostResearch: true`，并启动新的应用进程；热重载无法重新开放已安装拒绝守卫的进程。浏览器草稿和研究角色无法启用它。
2. 通过主机管理打开网络范围。配置目标和操作策略、批准的动作审核器及强制本机轨迹采集。构建运行时并显式应用已保存版本；若研究已在运行，请审核确认内容。参阅[包配置](../../../../packages/experimental/course-runtime/README.zh.md)。
3. 确认设置不完整时隔离 Linux 被禁用，且本机工具调用返回仅限管理的拒绝结果，不产生工具效果。观测到就绪后，确认根导航进入 `/runtimes/course/`。返回主机管理后，本机工具执行仍必须被拒绝。
4. 开课前单独审核现有的本机后台进程。此插件在讲师 Web 组合中安装进程生命周期的 ToolRuntime 拒绝；它不会追溯增加操作系统隔离，也不会改写无关的无界面配置。

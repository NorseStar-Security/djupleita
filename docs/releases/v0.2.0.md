# Djupleita v0.2.0

- Add a configurable Red team action profile: allow routine research and reconnaissance, send unknown effects to the isolated model risk judge, and retain explicit review or blocking for destructive actions. Scope and credential controls remain independent.
- Clarify the assistant context for bounded active assessment work. Formal owner assertions apply to the structured proof workflow rather than every active check.
- Support explicit, rate-limited httpx URL batches and improve Linux recon output and upstream-error reporting. Public DNS research does not require optional intelligence-provider credentials.
- Show time-budget expiry and provide owner-only renewal that preserves request usage.
- Add Evidence graph beside Chat and Trajectory, with engagement-wide search, tool collections, relationship navigation and supporting capture metadata.

Portable downloads support Linux and macOS on x64 and ARM64. Each archive includes its runtime and records the source revision in release.json. Verify downloads against SHA256SUMS. Configuration and assessment data are not included.

See [portable release instructions](../release.md) for setup and upgrades.

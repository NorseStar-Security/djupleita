# Djupleita · Scoped crawling

A shared crawl frontier that prioritizes coverage within the engagement scope and budgets.

Open **Crawl** for seed URLs, queue and progress, start/stop controls and persistent crawler limits. **Graph** shows discovered hosts and endpoints in the shared evidence graph. **Open shared engagement policy** takes you to Engagement and identities for the global scope, approvals, action profile, budgets and credentials. This plugin has no separate scope policy.

Enable or disable the crawl tool in **Plugins**. Other pentest tools retain the shared engagement controls. See [plugin settings](../../docs/plugin-settings.md).

# @deepseek-ai/dsh-experimental-assessment-memory

[English](README.md) | 中文

## 概述

保留同一业务历次评估的发现和操作历史。解释有证据支持的能力路径、检查计划覆盖范围，并在支持事实变化时生成复测工作。会话绑定评估后，结构化侦察结果自动更新图；浏览器和终端发现需要显式提交并附证据。业务和评估由操作员配置。发现的关系和候选路径绝不授予联系目标的权限。

## 使用此包

将这个可选 Host 插件与 Tools、System Prompt 和 Storage Domain 一起挂载。使用已有的 SQLite 域路由，或显式配置存储插件。数据库和组合配置应由操作员控制。每个业务使用不同的域名。域名由小写字母、数字和下划线组成，并以字母开头。

```yaml
- name: '@deepseek-ai/dsh-storage'
- name: '@deepseek-ai/dsh-storage-sqlite'
  config:
    path: /operator-data/assessment-memory.sqlite
- name: '@deepseek-ai/dsh-storage-domain'
  config:
    backend: sqlite
- id: assessment-memory
  name: '@deepseek-ai/dsh-experimental-assessment-memory'
  config:
    businessId: example
    businessName: Example Business
    assessmentId: example_2026_october
    objectives: ['Assess the approved public services']
    scopePolicyHash: REPLACE_WITH_CURRENT_SCOPE_STATUS_POLICY_HASH
    validFrom: '2026-10-01T00:00:00.000Z'
    validUntil: '2026-11-01T00:00:00.000Z'
    domainName: example_assessment_memory
```

加载前替换示例中的业务、目标、日期、数据库位置和策略哈希。不要重复注册配置中已有的存储提供方。[配置目录](../../../docs/config-catalog.zh.md#deepseek-aidsh-experimental-assessment-memory) 列出配置项；[服务格式](src/index.ts)定义默认值。插件本身不会采集、扫描或调度任务。

会话开始时调用 `memory_begin`，准确填写环境、身份和网络视角。该操作持久化不可变的会话绑定并返回当前上下文。执行侦察需要此绑定。操作前先查询相关资产和尝试。工具和运行时提示通过常规 Harness 模型接口提供，无需单独实现代理循环。

通过 `memory_schema` 获取精确 JSON 提交格式，再用 `memory_record` 显式记录观察和操作。保留每次提交的重试键；相同键不能提交不同内容。引用的资产和记录必须存在。任务使用预期版本和到期的独占认领，只有当前认领者可以结算。新资产生成审查任务，观察发生变化时生成后续审查任务，但不会自动执行。大型回执返回有界标识符列表和明确的截断标志；其余观察可通过查询获取。

证据提交包含来源、位置、SHA-256 内容哈希、摘要和观察时间。原始证据保存在所引用位置；插件不会复制或认证原始证据。记录保险库引用而不是凭据值。使用 `retract` 撤销缺乏支持的断言，同时保留历史。采集失败或空清单不会删除已有资产。

身份、资源和业务服务观察可以携带由 provider、realm、nativeType 和 nativeId 组成的 `identity`。即使显示名称变化，该元组仍决定业务内的稳定标识；不同账户或租户域保持区分。DNS 名称、地址和端点保留独立标识。应使用权威原生标识；此机制不验证所有权，也不合并不确定的别名。观察查询同时提供 observedAt 和 recordedAt。

记录 `objective`，将现有业务服务资产与目标资产、负责人、影响及成功标准关联。`capability` 描述绑定环境、身份和网络视角下的有向操作，需要当前直接观察的支持、有效时间区间、条件、精确验证方法和配置指纹。每个 `requires` 前提均为 AND 要求。导入、推断、撤销或被取代的观察不能建立能力支持。即使证据也需要重新验证，已阻断能力仍保持阻断状态。

`memory_paths` 在精确资产标识之间搜索受限的简单路径，并解释支持证据、条件和前提分支。前提能力贡献控制能力前，其源必须可从假定入口到达。深度、检查边数和结果上限均显式报告；截断或空搜索不能证明不存在路径。入口控制仍是假设，需要评估证据。使用 `path` 记录及其业务目标持久化选定路径，固定能力和目标版本供后续比较。

能力只有通过同一评估中有效、已完成且确认的尝试才能标为已验证；尝试必须匹配验证方法、配置指纹及访问上下文，覆盖两个端点，且不早于能力证据。支持观察必须保持不变。只有每一步及其前提均满足条件，路径才被标为已验证。验证是有归属的评估声明，不代表独立审查批准或授权。证据信心与执行可行性分开，绝不是成功概率。

事实变化、撤销和依赖版本变化会使依赖路径和能力失效。同一持久化事务生成去重的 `retest:` 任务。每次查询均计算是否到期；到期产生的持久化复测工作在下一次日志操作时生成。复用结论前，应替换陈旧证据、记录新的匹配尝试、更新相关能力并显式修订路径。历史复测任务需要显式认领和结算；新断言不会静默关闭以前的工作。

使用 `coverage-plan` 记录为目标定义资产、测试、上下文和配置单元。`coverage-matrix` 视图区分未测试、执行失败、被阻断、无法确定、已确认和未复现，并将支持变化或到期的尝试标为需要重新验证。不同访问条件或配置指纹的尝试不能填充单元。未复现仅适用于记录的测试和条件；计划覆盖范围不代表资产清单完整。

尝试保留方法、工具版本、访问上下文、配置指纹和适用截止时间。查询标记已到期的尝试、发生变化的受支持观察和不匹配的会话上下文；操作员仍需判断提交的配置指纹是否适用。验证修复需要当前评估中时间更晚、覆盖相同发现资产、已完成且未复现问题的尝试，同时要求受支持观察未变、适用期限有效及原始发现访问上下文一致。清理状态和防守方结果均为显式报告的证据声明。

进行下一次评估时，保留业务标识和存储域，配置新的评估标识及当前目标、日期和策略哈希，再创建新会话。历史知识仍可查询。评估标识相同时更改元数据会失败。评估到期后仍可读取历史；新的记录操作需要有效评估。

`memory_status` 报告待处理采集、故障、适配器覆盖范围和结果未知的派发。自动接收失败会锁定降级状态并阻止后续被记录的执行。修复存储或配置后重新加载；重复可能改变状态的操作前，应根据会话证据核对未完成操作。日志达到上限时不会静默丢弃旧记录。操作员归档或更改配置前应备份数据库。

`memory_rage_export` 返回完整 RAGE v0.1 NDJSON 图，包含署名、证据链接和显式评估扩展。`memory_rage_import` 接受受限大小的受支持包，保留原生节点标识和类型元数据，并将导入关系记录为未经验证的假设。导入不会认证上游证据。操作记录与能力分析保留在 `memory_query` 和日志中，不包含在图交换中。导出节点标识保留原生身份元组。按格式要求忽略未知 RAGE 记录类型；不支持 ZIP 包装。

## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

[服务](src/index.ts) 通过 Storage Domain 串行写入不可变且经过格式验证的日志事务。写入前先验证候选投影，仅在存储确认持久化后发布新投影。重放时先验证序号、事件标识和载荷哈希，再重建状态。这些哈希检测意外不一致，无法认证可被攻击者重写的数据库。域后端负责物理存储和文件权限。

Tools 执行包装器在已绑定调用进入执行器前记录派发意图。不可变最终结果观察器记录结果并调用 [侦察适配器](src/recon.ts)。执行与结果采集之间发生崩溃会留下未完成派发，其外部影响仍未知。采集回执作为可忽略的插件记录进入发起会话。注册项和排队写入归插件生命周期所有，卸载时排空。

[投影](src/state.ts) 将断言与当前资产分开保存。稳定标识规范化 DNS 名称、IP 地址和 HTTP 端点标识，排除端点查询字符串和片段。侦察提供方保留的 DNS 所有者名称支持精确的地址和别名关系。冲突观察及其来源和时间均被保留。[RAGE 适配器](src/rage.ts) 导出结构性自定义关系，不赋予攻击者遍历语义。它不执行 RAGE 规则库，也不证明可利用性。

</details>

## 模型体验

### 评估上下文、工具和结果

#### 模型能看到什么

插件注册 `memory_begin`、`memory_query` 等记忆工具，并提供必需的动态运行时提示。绑定前，提示引导模型开始评估。绑定后，提示提供已配置业务、评估、访问上下文、日志版本、未完成任务数、未知结果数、能力/路径/覆盖计划计数和采集健康状态。提示要求模型在复用结论前检查路径解释和复测工作。详细检索通过受限查询显式完成。工具格式和通用卡片在原生及嵌套执行中暴露相同操作。

#### Token 影响

挂载期间请求携带固定工具格式。动态上下文包含受限标识和计数，而不是完整图。记录格式检索、查询页和导出按需追加结果文本，并在适用位置限制大小。加载完整记录格式的 token 成本高于普通查询。

#### KV Cache 影响

工具结果追加到历史。运行时上下文随日志状态变化，并通过现有持久化提示机制物化。挂载、卸载或修改工具定义会改变工具格式前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 每个服务实例配置一个业务和评估；数据库权限与操作员控制的配置提供隔离。会话绑定用于归属记录，不是身份认证。共享多租户托管需要单独的授权层。
- 图与日志投影驻留进程内存。Storage Domain 提供单进程写入；不支持分布式工作进程或多个进程共享同一域。不提供自动日志压缩、迁移或加密证据保险库。
- 自动资产提取仅支持被接受的 `recon_run` 结果。其他已绑定工具结果记录哈希和会话引用；显式记录前其覆盖状态保持未解析。崩溃后不会在后台重放遗漏的会话结果。
- 建议任务不会自动执行。不安装周期调度、云采集器、RAGE 推导引擎或图可视化。自定义关系保持结构性质；已验证假设是被记录的证据声明，而不是独立验证。
- 不提供所有权验证、可逆实体合并、独立审查者认证、历史时点查询或旧式关系假设的自动重新验证。能力路径使用显式提交的断言，不使用导入规则库。
- 导入验证受支持的记录字段及本地节点与边引用，不验证整个上游分类、规则库或原始证据链。导入关系被规范化为假设，不保证无损 RAGE 往返。证据位置必须通过其所属系统保持可用。
- 完整字节限制可能拒绝查询或导出；应缩小查询或增加操作员配置的限制。并发写入会使偏移分页发生移动。格式工具返回固定格式，而不是任意大小的图。

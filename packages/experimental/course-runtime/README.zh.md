[English](README.md) | 中文

## 概述

在任一运行环境中配置网络范围和侦察，部署控制始终位于本机 Mac。保存创建待应用版本；应用会先停止所有研究进程，再选择不可变配置。本包仍为实验性功能。

## 使用本包

在插件中启用网络范围包并打开其页面。保存目标策略、操作限制及动作审核配置，选择讲师批准的审核模型，构建 ARM 运行环境，然后应用待应用版本。环境运行时需要选择停止并应用。空的操作或审核设置不会授权研究。应用会继承本机已启用的 bundle、模型路由及其产品存储 API 密钥，并保留后续在隔离环境中的模型覆盖设置。在所选后端的设置 → 模型中配置覆盖值；账户登录需要单独认证。转发本机环境变量仍仅限显式 OPENAI_API_KEY 选项。

本机应用默认为主机管理：其 ToolRuntime 调用被拒绝，根客户端会打开设置页，直到观察到隔离 Linux 的网关健康、动作审核就绪、轨迹采集成功，且保存版本、应用版本及运行版本一致。随后客户端跳转至隔离环境，不会悄悄回退至主机执行。通过主机管理返回并编辑范围或查看本机设置；此导航不会授予工具执行权限。各位置保留独立的浏览器状态。未知或失败的观测会禁用隔离环境选择；该标签表示位置，而非安全认证。

部署所有者可在启动新进程前，于讲师 `course-runtime` Cordis 配置项中设置 `allowHostResearch: true`，允许可信主机研究。默认值为 `false`；浏览器草稿无法修改它，研究角色也无法启用它。默认拒绝的讲师模式一旦挂载，卸载或重新配置插件都无法移除其进程生命周期主机守卫；更改此例外需要重启应用。新进程中的显式启用仅省略本包的拒绝，不会移除其他守卫或网络策略。`archivePollIntervalMs` 默认为 2500 毫秒（范围 1000–60000）。更改选择器不会迁移、终止或追溯约束已有进程。升级现有课程部署前，请参阅[主机管理迁移指南](../../../docs/upgrade-guide/v0.2.1-alpha.3/course-runtime-host-management/guide.zh.md)。

## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

本机控制器将草稿、不可变版本、操作状态及生成的 Compose 配置保存在被忽略的 harness-local 主目录下。版本检查拒绝陈旧保存；较旧的状态轮询不会覆盖较新的已保存编辑版本。进程锁串行化生命周期操作。HTTP 和 WebSocket 桥接通过本机连接认证，仅转发独立研究凭据。研究环境获得只读策略，不含 Docker 套接字。私有启动快照通过受控进程的标准输入及不可变配置卷传输；浏览器状态不会包含模型密钥。引导脚本保留导入字段以外的 YAML 标签，并私下保存上次导入值以进行三方合并。

强制本机采集通过经过认证的只读接口，将有界持久化记录拉取至讲师收集器，并使用独立安装标识。只有完整持久化的轮询才能续期网关的本机专用归档租约；首次续期前或租约到期后，新的受审核工具准入会失败关闭。课程默认租约为 30 秒，可通过 `actionReview.archiveLeaseSeconds` 配置。采集或续期失败会显示错误并请求停止运行时。卸载必需的收集器、投影或配置服务时，会等待在途持久化回执结束，并在研究运行时请求停止；若无法确认停止，有界网关租约仍会到期。本机 cookie 和收集器写入凭据不会进入研究环境。这些完整记录来自研究工作进程：它们并非防篡改的独立观测，无法证明每个进程或网络动作；此拉取器也不复制附件二进制内容。

</details>

<a id="model-experience"></a>
## 模型体验

间接地，通过 ToolRuntime 结果：本机工具调用默认收到 `Native host research is disabled. Configure and use the Isolated Linux runtime; the host is management-only.`。隔离研究组合不会获得此主机守卫；其范围与动作审核插件负责相应结果。本包不会增加模型请求或工具。

#### KV 缓存影响

不会更改系统提示词前缀。被拒绝的本机调用会向会话添加普通工具结果消息；研究提供程序及工具负责其他缓存影响。

## 已知限制及延后工作

<a id="known-limitations-and-deferred-work"></a>

- 支持一份共享策略及一个隔离 ARM Colima 环境。会话及工作区卷保留在原后端。切换不会迁移会话或停止后台工作。应用失败后研究保持停止，用户必须审核后重新应用。其他被动来源需要明确审核的基础设施权限。
- 本机准入覆盖通过 ToolRuntime 发起的调用；它不是操作系统沙箱，也不会改写无关的无界面配置。默认拒绝的讲师模式一旦挂载，其拒绝会在插件卸载和 Tools 提供程序替换后继续存在，直到应用根退出。归档租约到期会拒绝新的受审核工具准入，但不会撤销已运行工具产生的外部影响。

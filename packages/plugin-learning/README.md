# Optuna learning

Included with Djupleita. Use Studies to improve how the agent works:

- **Optuna** adjusts numbers that decide which pages to crawl first. Score them using saved examples and request costs.
- **GEPA** improves a testing checklist. It tries saved examples, reads feedback on mistakes, and rewrites the instructions.

Run `pnpm setup:tools --only learning`, then load local setup in the plugin. GEPA uses the chat's selected model; provider charges apply. Python stays confined without network, credentials or assessment tools. Datasets, hashes, split isolation, reports, trajectories and explicit owner promotion share the same learning service. Scope and approval policy cannot be optimized.

Review the old and new checklists, scores and example answers in Studies. **Promote procedure** saves the checklist for future chats, including after restart. **Disable procedure** stops future use. Promotion requires better results on the comparison examples and no worse results on the final examples kept aside.

See the [account-access example guide](../../configs/datasets/shop-authz-procedure.md), [crawl-ranking example guide](../../configs/datasets/shop-authz-ranking.md).

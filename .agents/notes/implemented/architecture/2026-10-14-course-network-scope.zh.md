# Agent Note: 工具分发之下的课程目标范围

Status: implemented

[English](2026-10-14-course-network-scope.md) | 中文

## 问题

参数适配器无法约束任意程序、浏览器脚本、重定向、service worker 或子进程选择的目标。拒绝全部未识别工具会阻止课程使用这些研究能力。在没有执行边界时允许它们，则无法强制执行范围。

## 决策

可选的[课程运行时](../../../../course/scope-runtime/README.zh.md)在专用 Linux 命名空间中以非特权身份运行工具。独立拥有的网关安装基于 UID 的 nftables 输出规则，并中介域名 HTTP(S)、WebSocket 和 DNS。显式 IP/CIDR 授权允许直接套接字连接。域名 DNS 答案绝不转为原始 IP 授权，因为共享托管不能证明公司归属。

HTTPS CONNECT 在临时课程 CA 处终止，使网关能够比较内部 Host 与获准目标。研究容器不能访问 CA 私钥、修改策略、获取 capability 或控制 Docker。私有回环允许本地浏览器控制。监督进程退出后，内核过滤仍然保留；数据包监控丢失会停止监督进程，而不是在缺少监控时悄悄继续运行。

仅检查参数的裁判仍可用于受限的结构化工具部署。课程补丁改为挂载 Cordis 范围服务提供者与裁判/审计消费者。抽象服务定义只读检查，Linux 提供者读取教师拥有的 Unix 套接字，消费者在分发前检查映射目标并保留环境网络记录。目标约束仍在插件权限之外，因为即使插件被卸载，每个工具及子进程也必须经过它。

网关不提供策略修改 API。带序号的有界日志使审计丢失显式可见；消费者通过单个游标串行化轮询与预检，并在游标被覆盖或身份变化时停止分发，直到教师调查并重新加载。网络记录是可忽略的实验性 Session 数据，不是模型指令或逐工具因果归因。确定性的无密钥 CLI 快照拥有模型可见状态、终端允许与分发前拒绝证据；Linux 套件拥有实际网络计数证据。

## 考虑过的替代方案

**枚举并阻止能力。** 这会拒绝浏览器/代码/终端研究，而非授权目标，且每个新适配器都会重复相同的不完整中介问题。

**仅使用浏览器路由钩子或 origin 列表。** 它们不覆盖非浏览器工具，且钩子对重定向、service worker 和 WebSocket 的覆盖各不相同。课程允许 service worker，并测试底层边界。

**开放域名解析 IP 或不透明 CONNECT 隧道。** 共享 IP 允许访问其他主机名，而隧道无法验证内部 HTTP authority。显式原始 IP 范围仍是教师的独立决策。

**让特权研究者共享网关命名空间。** NET_ADMIN 能修改防火墙，NET_RAW 能创建普通套接字过滤之外的数据包路径。此拓扑丢弃所有 capability；特权扫描器需要路由式外部执行边界。

## 后果

浏览器、代码、终端及 TCP 连接工具无需命令解析即可继续用于获准目标。TLS 检查需要实验信任配置，并向可信网关暴露明文。证书固定客户端及不支持的协议可能以拒绝方式失败。显式 IP 范围无法区分虚拟主机或公司归属。外部执行器和服务端跳转需要独立控制。

[验证驱动](../../../../course/scope-runtime/verify.py)观察允许/禁止服务器计数，验证故意引入的防火墙回归，并测试监督进程丢失。它拥有唯一 Compose 项目并删除其临时资源。这些测试不证明在线模型使用、原始扫描、抗逃逸、入站策略或逐 Session 审计归因。

网络套件已在 Docker 下通过，包括并发实例和注入的监控故障。完整 DSH 镜像仍待验证：本地模拟 Linux 构建完成了 TypeScript，但上游打包器触发 V8 致命检查并以 132 退出。这是运行时原型，不是已经验证的可直接运行的 DSH 部署；请在专用 Linux 课程主机上验证构建后的配置档。

# Agent Note: 收集轨迹的执行索引

Status: implemented

[English](2026-10-15-collected-trajectory-trace-index.md) | 中文

## Problem

课程观察者需要检查长时间 Agent 运行，既不能让浏览器加载完整对话，又必须保留可审计的精确记录并支持可选远程查询。直接渲染原始 OTLP 日志不能表达执行层级与持续时间。如果派生轨迹复用收集器日志确认位置，可能在只成功交付一种信号后丢失另一种。

## Decision

[投影插件](../../../../packages/experimental/trajectory-projection/README.zh.md)从已提交的收集器记录增量生成独立私有 SQLite 索引。确定性轨迹与跨度身份、持久源游标、归档锚点及投影世代用于区分重试与归档替换。[查看器](../../../../packages/experimental/trajectory-viewer/README.zh.md)查询有界分页，并单独读取精确源记录，不修改源会话或 Agent 循环。

[轨迹导出器](../../../../packages/experimental/trajectory-export-otlp/README.zh.md)使用自己的检查点、锁及目的地绑定读取不可变已完成跨度。整个请求被确认后只推进轨迹游标；收集器日志确认保持独立。子会话关联只依据同一安装实例的记录证据，不伪造父跨度或跨轨迹链接。时间描述已记录观察，而非无法观察的网络派发。

## Alternatives considered

**仅在浏览器折叠。** 每个观察者都要重放大型历史，刷新后派生状态丢失，因此拒绝。源记录仍可读取，但不要求每个视图加载全部记录。

**仅使用原始 OTLP 日志。** 保留为完整远程证据，但日志缺少父跨度层级和持续时间，不足以独立提供执行可视化。

**共享日志与轨迹检查点。** 两种信号交付结果不同，跨度完成顺序也不同于源到达顺序，因此拒绝。独立持久游标允许重放而不静默跳过另一种信号。

**强制远程服务。** 课程必须可以本地运行，且学生镜像中不能包含共享凭据，因此拒绝。教师配置的远程导出为可选项；注册和学生上传授权仍是独立、尚未实现的集成工作。

## Consequences

本地查询有界且可重启，代价是第二个私有数据库及索引延迟。投影故障和延迟可见；历史缺失时停止索引，不虚构连续性。完整记录不截断，因此异常大记录可能需要显式导出而非界面检查。收集器及索引由教师保护；收集原生持久化目录不会自动收集独立 Protected Docker 卷。

# Agent Note: 课程遥测注册与远程轨迹保管

Status: proposed

[English](2026-10-15-course-telemetry-enrollment.md) | 中文

## Problem

学生获得相同的 Linux 课程镜像，需要在不配置 API 密钥的情况下实现远程轨迹监控。镜像中的共享凭据可以被提取，无法可靠识别不同学生，也无法单独撤销某个安装实例。向研究 agent（智能体）提供 Logfire 项目 token 还会赋予其不必要的可观测性服务访问路径。

## Proposal

将教师运营的注册及经过身份验证的接收服务列为必需的部署假设，而非现有功能。在以下验收标准通过之前，不得以支持自动远程监控的方式分发镜像。[教师侧收集器](../../../../course/trajectory-collector/README.zh.md)独立地将已存储的轨迹导出至 Logfire；它不实现学生注册、上传或身份验证。

注册通过显式的“连接课程”操作和课程身份提供方的 OAuth 设备授权流程完成。学生在宿主浏览器或其他设备中完成 SSO，而非研究浏览器。公开的客户端标识属于配置，不是秘密。首次启动的安装实例生成自己的密钥和注册身份；创建镜像时不得复制已注册的实例。服务检查课程成员资格，并根据经过身份验证的注册结果确定学生、班级及安装实例身份，绝不采信事件属性中的身份声明。

注册代理签发有效期短、受众受限且仅可写入的接收凭据。收集器侧凭据提供方负责续期并保管权限有限的刷新凭据；研究进程无法读取二者。支持单实例撤销及课程到期。在身份提供方和部署支持时，选择发送方约束凭据（DPoP 或 mTLS）。OAuth 设备流程及原生应用指导由 [RFC 8628](https://www.rfc-editor.org/rfc/rfc8628.html) 和 [RFC 8252](https://www.rfc-editor.org/rfc/rfc8252.html) 定义；token 保护遵循 [RFC 9700](https://www.rfc-editor.org/rfc/rfc9700.html)。

接收服务首先进行身份验证，执行按身份配额，写入可信身份，并且仅在将完整事件提交到本地持久存储后才确认接收。稳定的来源、会话和事件标识支持回放去重。其持久化提供方随后向 OTLP 导出器供给数据；只有教师环境持有 Logfire 写入 token。将注册、凭据存储、接收、持久化及导出保留为可独立替换的 Cordis 插件。不得修改 agent loop（智能体循环），也不得放宽[研究网络策略](../../implemented/architecture/2026-10-14-course-network-scope.zh.md)以允许任意可观测性访问。

### 交付计划

1. 通过显式启用的 OTLP 消费方将教师可访问的已持久化轨迹导出至 Logfire，保留本地历史及确认检查点。
2. 构建经过身份验证的接收 API 和持久化本地收集器，包括可信身份写入、配额、去重、保留控制及检查 UI。
3. 使用现有 harness 授权扩展点（适用时），添加课程注册代理及收集器侧授权和凭据插件。
4. 接入镜像的连接、续期和断开连接体验，并在课程发布前验证离线恢复、撤销及新克隆实例注册。

## Alternatives considered

**嵌入一个全班共享的 Logfire token。** 否决，因为每个镜像接收者都能提取它、冒充整个班级并耗尽项目接收额度；轮换会中断所有人的使用。

**要求每位学生配置个人 API token。** 否决，因为这将部署管理负担转移给学生，且不符合约定的连接体验。

**将生成的 VM 标识视为身份验证。** 否决，因为标识既不是课程成员资格，也不能证明遥测发送方可信。完全相同的离线镜像若没有注册或外部置备信任，就无法安全地自行完成身份验证。

## Acceptance criteria

- 干净镜像不包含注册、刷新、接收或 Logfire 秘密；独立克隆实例生成不同的注册密钥，并要求显式连接。
- 已注册学生无需复制秘密即可通过课程 SSO 连接。非成员、过期设备码、错误受众、已撤销实例及已到期班级均无法上传。
- 续期自动进行，并经过到期及离线场景测试。退出登录或撤销只使该实例失效，不影响同学。敏感凭据及设备码绝不进入轨迹内容或诊断日志。
- 服务器拒绝未经身份验证的上传，忽略伪造的学生或班级声明，限制资源使用，并在确认前提交数据。磁盘满或存储不可用时不确认；重启及回放对已接收的事件标识去重。
- 镜像的研究进程无法访问收集器凭据、Logfire 凭据、收集器配置或通用远程执行器。运维连接与目标授权保持分离。
- 恢复后，完整的已持久化事件内容及范围审计记录到达远程项目。本地保留策略及磁盘告警保护尚未确认的历史；课程已批准保留、隐私通知和访问控制。

## Risks

掌握 root 或虚拟机管理程序控制权的学生能够检查安装实例秘密、屏蔽事件或伪造轨迹。注册识别的是凭据持有者，并不证明执行过程可信。更强的证据需要教师托管 VM，或经单独审查的证明机制。完整轨迹可能包含秘密和个人数据；应使用实验账户并明确征得收集同意。远程副本覆盖持久化事件，不覆盖本地持久化之前丢失的数据、未引用的二进制产物或 harness 之外的任意活动。
